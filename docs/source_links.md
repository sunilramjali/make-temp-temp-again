# Source links

Every source used in the Newham evidence brief ([`newham_evidence_brief.md`](newham_evidence_brief.md)), with how far it was checked. The repo is public: these are all open, published documents.

**Status key**
- **Read in full**: the file is saved locally and the numbers or text were read directly from it.
- **Search result only**: a search snippet or news report. Not checked against the primary document. Don't quote these as fact without checking.
- **Not opened**: link found on an official page, not yet read.

Dataset files are logged in [`data/sources.csv`](../data/sources.csv). Policy documents are in [`policy/newham/`](../policy/newham/).
